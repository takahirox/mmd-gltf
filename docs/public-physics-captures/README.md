# Public physics comparison canvases

The sixteen PNGs show the pinned real Uka / Gene Light models at Laugh / Apology
frame 15 (0.5 s), paused, IK On. Names identify model, motion, optional `pbr`, and
Physics `on` / `off`. Each full canvas shows independently rendered direct PMX on
the left and glTF Toon (or PBR) on the right. These are captured render bitmaps,
not image comparisons against native Windows MMD.

Generated by [the real-model browser tests](../../tests/browser/public-physics.spec.ts).
Pixel/pose measurements, browser environment and SHA-256 hashes are in the
[execution report](../public-physics-validation.json). The
[validation discussion](../physics-validation.md) records nonzero constraint
residuals and performance limits alongside the observed motion.
