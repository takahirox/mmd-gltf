`tests/browser/physics.spec.ts`. Current unified interface screenshots and results
are recorded in the [Issue #49 validation record](../unified-demo.md).

appearance state. The JSON Demo report records the matching resolved transforms,

browser display composition; exact restoration assertions use nonempty intrinsic
