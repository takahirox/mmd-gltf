# Issue #41 built Demo canvases

Original synthetic group rigs and motions by mmd-gltf contributors. No third-party
assets or original-MMD captures. These are actual built Demo canvases on Chromium
WebGL2 / SwiftShader with pinned Three.js 0.186.1.

Both rigs, both motions and all three source paths have Toon/core PBR with
outlines on/off. Additional captures show manual group controls, reset, both VPD
poses and the held-frame negative control. The
[frame record](../group-demo-validation.json) maps every image to its matching
submitted revision, weights, sampled deformed vertices and SHA-256. See the
[measured validation](../group-validation.md) for independent scalar/raster limits.
