# Physics palette conformance canvases

Generated by `tests/browser/physics.spec.ts` from the built conformance page.
Names identify rig, skinning mode, Toon/PBR material, motion or VPD handoff and
surface/outline pass. Each PNG is captured immediately after the render whose
independent resolved palette is compared in the corresponding numerical report.
These are synthetic/backend conformance images, not original-MMD measurements.
