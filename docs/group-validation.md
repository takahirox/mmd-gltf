# Issue #41 group validation

The [contract](vmd.md#vertex-group-compilation-issue-41) compiles one-hop
vertex-only groups into independent core targets. Existing synthetic assets remain
byte-identical. New source/fixture provenance is recorded in the
[fixture README](../tests/fixtures/README.md#issue-41-vertex-group-fixtures).

`tests/group.test.ts` exercises deterministic API and CLI conversion, GLB/unpacked
glTF, direct VMD bytes, extension playback, ordinary core fallback, malformed
counts/references/rates/FLOAT results, failure atomicity, unsupported dependency
diagnostics, empty groups, byte maps, duplicate names and compatibility. Independent
decimal scalar predictions cover source keys and the same 1201-point grid, with
weight tolerance 1e-6 and BDEF position tolerance 2e-6 m. The explicit manual
0.3 + 0.8 × 0.5 example checks geometry and independent stored weights.

`tests/browser/group.spec.ts` adds both rigs/motions through bytes/GLB/glTF to the
built Demo and records rendered revisions, independent deformation predictions,
Toon/core PBR, outlines on/off, actual loop crossings, paused controls, both VPD
apply/reset handoffs, manual group apply/reset, failed-file recovery, replacement
and disposal. A held-frame negative control requires the matching render after
control changes. The shared VMD raster harness's `?group` mode uses independently
baked scalar geometry with the existing 128-pixel limit (per-channel differences
above 2), minimum foreground coverage, and exact reseek restoration. Applied
motion/VPD states traverse existing core GLTFExporter GLB/glTF paths and are
validated after reload, metadata/weights inspection, repeated VPD application,
reset and resumed VMD, without double deformation.

Focused group-before-SDEF/QDEF CPU and actual vertex-stage GPU probes reuse
independent advanced skinning predictions on both mixed rigs and both motions.
The existing advanced GPU, normal and raster suites remain mandatory regression coverage with unchanged
numerical thresholds (GPU position 1e-4 m, normal 5e-4). Node and browser checks
execute the lockfile's Three.js 0.186.1.
