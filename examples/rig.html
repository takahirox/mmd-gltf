Original synthetic PMX rigs, VPD poses and VMD motions by mmd-gltf contributors; authored in this repository, no third-party assets. The original rigs retain BDEF1/2/4; their mixed SDEF variants retain ordered pairs, zero/nonzero centers and vertex morphs. QDEF variants use the bounded PMX 2.1 rigid-dq-v1 profile with mixed BDEF/SDEF/QDEF and an approximate BDEF4 fallback. All retain duplicate exact names, forward parents, two materials and joint 259. The wedge has different geometry and hierarchy. Apply replaces all joints relative to original rest; omitted bones return to rest. Reapplication never accumulates offsets. Reset also works after loading a posed GLB with the reusable API.

IK/append presets execute the bounded pre-physics-v1 project profile in layer/index order. Physics presets add bounded rigid bodies, spring joints and post-physics append. Other presets retain their existing behavior. Fixed-axis-dependent IK, general multi-axis IK, external parents, soft bodies, impulse morphs, other morph families and scene VMD execution remain unsupported. Vertex morphs and one-hop vertex-only groups use independent additive core POSITION targets before skinning, preserving authored normals. VMD uses continuous destination-key curves, including adjacent frames; original-MMD equivalence of this project profile is unresolved. Applying/resetting VPD pauses motion and preserves weights; playing or seeking motion restores original-rest ownership. Converted files include approximate core TRS and LINEAR weight animation for ordinary loaders. A pose's parent filename and motion's model name are informational and never fetched.
