Direct PMX via @takahirox/three-mmd@0.1.2 alongside a static adaptation using the MMD_materials_toon v0.1 draft. Compare the independent PBR fallback using the menu above. Same pinned source, base pose, scale, camera, directional light and renderer; no animation, IK, physics, morph updates. Outlines use different algorithms: the PMX reference uses three-mmd’s legacy thickness law; glTF uses the normative MMD_materials_outline v0.1 pixel expansion and encoded RGB blending. Their thickness and appearance can differ. Neither view uses the original MikuMikuDance renderer. Original-MMD shading fidelity remains unverified; this comparison is a secondary diagnostic. Independent shading models can differ in brightness, ambient, toon and specular response. WebGL2 is the default; use ?backend=webgpu to try WebGPU.
