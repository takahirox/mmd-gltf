About & credits

The MMD label denotes a direct PMX-rendering reference using @takahirox/three-mmd, not native MikuMikuDance. The glTF side uses converter-produced assets. Exact MMD visual/physics fidelity is unverified; supported solvers and physics use bounded profiles. The public comparisons play the same pinned VMD on one frame/30 clock using raw bone offsets and vertex expressions. Uka optionally evaluates only its six source sleeve IK chains in both panes. Foot IK, grant/append and physics remain off; no Ammo world is initialized. This comparison excludes material, group, bone and UV morph deformation, VMD visibility/camera/light/shadow execution and unresolved names. Laugh · 02 and Apology · 22 provide authored upper-body and arm animation. Uka Apology also activates two group morphs (困る and 口締め): their facial contribution is deliberately omitted on both sides and preserved in the source. Other selected active morphs are vertex expressions. Manual expressions are available in Rest mode. Exact retained glTF playback replaces its corresponding approximate core animation channels.

Gene Light · source & rights

Direct PMX via @takahirox/three-mmd@0.1.2 alongside a BDEF skinned adaptation using the MMD_materials_toon v0.1 draft. Compare the independent PBR fallback using the menu above. Same pinned source, scale, camera, directional light and renderer. Official 01_happy.vmd retains a static skeletal pose with changing expressions; 02_laugh.vmd and Gene’s own 22_apology.vmd add authored body animation on the shared timeline. Only active vertex targets enter the preview GPU buffers; the downloadable conversion retains all supported targets. Outlines use different algorithms: the PMX reference uses three-mmd’s legacy thickness law; glTF uses the normative MMD_materials_outline v0.1 pixel expansion and encoded RGB blending. Their thickness and appearance can differ. Independent shading models can differ in brightness, ambient, toon and specular response. WebGL2 is the default; use ?backend=webgpu to try WebGPU.
